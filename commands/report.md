전날 git 커밋 내역과 현재 미커밋 변경사항을 분석해서 아래 템플릿으로 데일리 스탠드업 보고서를 작성해줘.

## 데이터 수집 방법

1. 아래 명령으로 git 데이터를 수집한다:
   - `git log --oneline --after="yesterday 00:00" --before="today 00:00"` (어제 커밋)
   - 어제 커밋이 없으면 최근 5개: `git log --oneline -5`
   - `git diff --stat HEAD` (오늘 진행 중인 미커밋 변경사항)
   - 필요시 `git diff HEAD -- <파일>` 로 실제 변경 내용 확인

2. 커밋 메시지와 실제 diff를 보고 **기능 단위**로 해석해서 작성한다. 파일명/함수명을 그대로 나열하지 않는다.

## 출력 템플릿

**전일 진행 업무**
- <기능 카테고리> [<소요시간 추정>h]
  - <구현 내용 1>
  - <구현 내용 2>

**오늘 작업 계획**
- <기능 카테고리>
  - <작업 항목 1>
  - <작업 항목 2>

**블로커**
- 없음

**이번 주 목표**
- <현재 브랜치/작업 테마 기반 요약>

## 규칙

- 블로커와 이번 주 목표는 사용자가 별도로 언급하지 않으면 기본값 유지
- 추가 인수가 있으면 블로커나 특이사항에 반영 (예: `/report 블로커: 배포 환경 미설정`)
- git repo가 아닌 환경이면 수동 입력 요청
